# ESP32 温湿度天气站

基于 **ESP32-WROOM-32E** 的开源温湿度天气站硬件设计，使用 **立创 EDA 专业版（EasyEDA Pro）** 完成原理图与 PCB 设计。

## 项目概述

| 项目 | 内容 |
|---|---|
| 主控 | ESP32-WROOM-32E（C2973652） |
| 传感器 | SHT30 温湿度（I2C：IO21/IO22） |
| 供电 | USB-C 5V / 锂电池（PH2.0）双供电，免维护自动切换 |
| 充电 | TP4056（C16581）+ 充电指示（IO16/IO17/IO25） |
| 电源 | AO3401A P-MOS 防反接 + HE9073 低压差 LDO（3.3V） |
| 下载 | CH340N（C8469）USB 转串口 + EN/BOOT 按键 |
| 扩展 | P1/P2 排针引出 8 个 GPIO |

## 设计特性

- **双供电自动切换**：USB 插入自动切 USB 并充电，拔出切电池
- **充电状态指示**：由 MCU 控制，可自定义闪烁/呼吸灯（CHRG_DET / STDBY_DET / LED_CTRL）
- **模组化布局**：电源带 / MCU / 传感器 / 下载 / 排针分档摆放
- **板载 PCB 天线**：ESP32 模组顶端天线伸至板边，上下层全禁铜
- **单面布局**：顶层元件 + 信号，底层整片 GND 铺铜
- **安装孔**：四角 M2.5 镀通孔（5×5 方焊盘地锚 + 2.65mm 钻孔）

## 使用说明

1. 安装 [立创 EDA 专业版（EasyEDA Pro）](https://pro.lceda.cn/)
2. 打开 `esp32.eprj2` 工程文件
3. 原理图 / PCB / 网表 / BOM 均在工程内可查看与编辑

> 工程文件为立创 EDA 专业版格式，使用其他版本的 EDA 软件可能无法直接打开。
